# IndexNow 集成审计

| 分类 | 结果 |
| --- | --- |
| A | 保留固定 HTTPS API、经公开地址校验的取证请求、限制正文、禁止重定向、429 退避及提交回执与索引状态分离。 |
| B | 站点配置强制完整 Key Location，旧任务一次只入队一个 URL，缺少统一验证、生成和轮换。 |
| C | 新密钥使用 8–128 位十六进制与连字符。旧键及同等旧验证行为在迁移期间保留，以便现有任务仍可恢复。 |
| D | 实际所有权文件、公网上游的受控提交和回执须在明确授权的测试 Host 验收。 |
| E | 200 表示提交成功，202 等待验证。它们均不构成收录证据。 |
| F | 旧完整 Key Location 把密钥包含在文件名里，配置列表展示该 URL。新架构只持久化非敏感目录，验证时在内存派生文件路径。 |

[IndexNow 官方协议与 HTTP 状态](https://www.indexnow.org/documentation)
