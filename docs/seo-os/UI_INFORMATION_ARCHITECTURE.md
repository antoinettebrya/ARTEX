## 工作流边界

- 关键词研究保留种子词。关键词拓展单独查看建议与相关词。关键词探索、历史、数据费用与竞争页面保留独立 URL，经相应研究页的关联链接访问。
- 内容项目列表与详情独立。文章编辑、质量审核和版本管理延续现有文档版本、审批和恢复 API。站点内容资产清单归入站点管理，并与 CMS 内容和媒体互通。
- SEO 执行按接入、发布、搜索、索引、优化与监控组织。发布中心、发布记录、页面验证、执行日志各有独立 URL。执行日志从现有组织审计 API 读取 Owner 可见事件。
- 规划模块包括站内链接、站群互链、AI 图片工作室、WordPress 主题工厂、Agent 管理、自动化工作流和组织级系统设置。技术 SEO 已覆盖现有页面提取与优化反馈入口。自定义站群分组、整站审计和自动修复属于后续能力。

## 统一站点范围与权限

全局「站点范围」在原页头打开。站点、区域站群、国家、语言直接使用当前组织的站点 API。区域站群按已登记的 `国家:语言` 计算，不写入业务数据库。浏览全部站点或站群时可以使用组织范围的页面。需要单站 ID 的执行、研究和项目页面会提示选择站点。

URL 以 `site_id`、`project_id` 为正式标识，仍解析旧的 `site`、`project`。范围使用 `site_id=all`、`site_group`、`site_country`、`site_language`。研究市场使用既有国家、地区代码、语言、搜索引擎、设备字段。它与站点登记的国家语言筛选独立。研究页的关键词可带入内容项目表单。切换范围清除之前的项目、发布包、关键词和任务上下文，筛选和选择写入历史记录。请求以范围 ID 为键，旧范围响应不会覆盖新界面。

当前角色为 Owner、Editor、Viewer。高权限写入、审计、费用和诊断继续由 API 判定，菜单也应用相同边界。现有 API 和数据库校验拒绝独立 Admin。交付未定义前端 Admin 权限或修改角色模型。

## 仪表盘统计口径

| 区域 | 数据与覆盖 |
| --- | --- |
| 站群状态 | 当前筛选范围内的站点总数和启用数来自 `/sites`。异常网站取组织最近 200 条任务中每站最新已完成任务失败。CMS 连接失败取同范围每站最新 CMS 验证失败。有观察时显示覆盖站点数。今日执行、成功率和失败任务来自当日创建记录，UTC。 |
| SEO 表现 | 已选单站的搜索报告来自 `/execution/metrics`。取近 28 个完整 UTC 日期，分别使用单一已启用连接。点击与展示为已同步明细之和，CTR 按点击与展示加权，平均排名按展示加权，自然流量使用 GA4 会话。索引取 `/execution/index` 中每个 URL 的最新观测。 |
| 内容运营 | 已选单站项目来自 `/content/projects`。最近 40 个项目详情用于核对文章版本和审核状态。无文章版本计入待生成，通过质量门且待批准计入待审核。已发布或已核验发布记录按 CMS 目标去重。 |
| AI 运营 | Owner 可见的组织级 UTC 今日数据。模型调用、Token 和费用来自 `/providers/receipts`，区分模型与 DataForSEO，排除测试及执行回执。Token 显示具有完整计量的回执覆盖。模型、DataForSEO 每日美元预算分别依据 `/content/usage` 与 `/research/usage` 中已计费与预留金额，按各自预算计算。 |

组织目录、分页报告和执行日志有读取上限，界面会说明部分数据或日期覆盖。无有效连接显示「未连接」。已连接但窗口无同步记录时提示「待同步」。单站接口的 SEO、索引与内容指标在指定站点后读取，站群范围继续展示实际站点和任务统计。
